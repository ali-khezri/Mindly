# Note Taking App

A full-stack note-taking application that allows users to create, view, and manage their notes through a clean and responsive interface.

## Features

- View all notes on the home page.
- Create new notes with a title and content.
- View the details of an individual note.
- Delete notes.
- Navigate between different pages.
- Responsive user interface for desktop and mobile devices.
- RESTful API for managing notes.
- MongoDB database for persistent data storage.
- Rate limiting to help protect the backend API.

## Technologies Used

### Frontend

- React
- React Router
- JavaScript
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- REST API
- Express Rate Limit
- Nodemon
